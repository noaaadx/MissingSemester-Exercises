## What this is

A public repository with notes and exercises from MIT's Missing Semester (2026 edition).

The goal is to understand and solve Linux exercises proposed by MIT.

---

## Structure

```
the-missing-semester/
├── lecture-01-shell/
│   ├── notes.md        # key concepts + commands
│   └── exercises.sh    # solutions with comments
│    
├── lecture-02-shell-tools/
│   └── ...
└── README.md
```

Each lecture folder follows the same pattern:
- **notes.md** — core concepts, commands, and anything worth remembering
- **exercises** — solution files with inline comments explaining the *why*
